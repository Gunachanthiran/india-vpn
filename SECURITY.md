# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in the WireGuard server scripts, FastAPI control plane, or mobile native bridges, please **do not** open a public issue with exploit details.

Instead, report it privately via GitHub Security Advisories on the repository with:
- Affected component (`server/`, `backend/`, or `mobile/`)
- Steps to reproduce
- Potential impact (e.g., key leakage, privilege escalation, tunnel leak)
