# iOS NetworkExtension Build Guide (macOS + XcodeGen + GitHub Actions)

## 1. Automated Cloud Build (Free on Public GitHub Repos)
The workflow [.github/workflows/ios.yml](../../.github/workflows/ios.yml) runs on GitHub's free `macos-latest` runner and produces **`IndiaVPN-ios-unsigned.ipa`**, compiling:
- The React Native host app (`IndiaVpnApp` + `WireGuardBridge.swift`)
- The `NEPacketTunnelProvider` app extension (`IndiaVpnExtension` + `WireGuardKit` + `libwg-go.a`)

### Important Apple Signing & Installation Rules
- **Unsigned `.ipa`:** Apple iOS does not permit installing an unsigned `.ipa` directly from Safari/Files on a stock iPhone.
- **Free Personal Testing (\$0):** You can sideload `IndiaVPN-ios-unsigned.ipa` onto your own iPhone using a **free** Apple ID via AltStore / Sideloadly (7-day expiry), **however** Apple restricts the `com.apple.developer.networking.networkextension` (`packet-tunnel-provider`) entitlement on free personal Apple IDs.
- **Zero-Cost Way to Share with Any iPhone User (\$0):** Every iPhone user can install the free official **WireGuard** app from the Apple App Store and import/scan the QR code generated by our FastAPI backend (`GET /api/v1/peers/{id}/qr`).
- **Branded Public iOS Sharing (TestFlight / App Store):** Requires an **Apple Developer Program** account (\$99/year) with the **Network Extensions (Packet Tunnel)** capability enabled for `com.indiavpn.mobile` and `com.indiavpn.mobile.network-extension`.

## 2. Building Locally on macOS

```bash
cd mobile
npm install
npx react-native bundle --platform ios --dev false --entry-file index.js --bundle-output ios/main.jsbundle --assets-dest ios

cd ios
mkdir -p Vendor/build
git clone --depth 1 https://github.com/WireGuard/wireguard-apple.git Vendor/wireguard-apple
sed -i '' 's|swift-tools-version:5.3|swift-tools-version:5.5|' Vendor/wireguard-apple/Package.swift
sed -i '' '1i\
#include <sys/types.h>
' Vendor/wireguard-apple/Sources/WireGuardKitC/WireGuardKitC.h
make -C Vendor/wireguard-apple/Sources/WireGuardKitGo ARCHS=arm64 PLATFORM_NAME=iphoneos IPHONEOS_DEPLOYMENT_TARGET=15.1 DESTDIR="$PWD/Vendor/build" build version-header

brew install xcodegen
xcodegen generate
RCT_NEW_ARCH_ENABLED=0 pod install
open IndiaVpnApp.xcworkspace
```

In Xcode, configure **Signing & Capabilities** (Network Extensions → Packet Tunnel + App Groups `group.com.indiavpn.mobile`) on both `IndiaVpnApp` and `IndiaVpnExtension`, then run on a physical iOS device.
