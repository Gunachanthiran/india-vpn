# iOS NetworkExtension Build Guide (macOS + Xcode)

Compiling the iOS WireGuard `NEPacketTunnelProvider` binary requires macOS and Xcode 15+.

## Zero-Cost Personal Testing vs. Public Distribution
- **Personal iPhone Testing (\$0):** You can build and sideload onto your **own** iPhone using a **free** Apple ID in Xcode (7-day provisioning profile, personal device only). Note that free personal Apple IDs may restrict `NetworkExtension` entitlements on some Xcode versions—if Xcode rejects `com.apple.developer.networking.networkextension` on a free Apple ID, you can still use the **official open-source WireGuard iOS App Store app** (free) by scanning the QR code generated by our FastAPI backend (`GET /api/v1/peers/{id}/qr`).
- **Public / External Distribution (TestFlight / App Store):** Requires an **Apple Developer Program** membership (\$99/year) with the `Network Extensions (packet-tunnel-provider)` entitlement enabled.

## Steps on macOS

1. Install JS dependencies and CocoaPods:
   ```bash
   cd mobile
   npm install
   cd ios && pod install
   ```
2. Open `IndiaVpnApp.xcworkspace` in Xcode.
3. Verify two targets exist:
   - **`IndiaVpnApp`** (`com.indiavpn.mobile`) — main React Native app containing [WireGuardBridge.swift](IndiaVpnApp/WireGuardBridge.swift) and [WireGuardBridge.m](IndiaVpnApp/WireGuardBridge.m).
   - **`IndiaVpnExtension`** (`com.indiavpn.mobile.network-extension`) — Network Extension target containing [PacketTunnelProvider.swift](IndiaVpnExtension/PacketTunnelProvider.swift).
4. Add **`WireGuardKit`** via Xcode → *File → Add Package Dependencies* (`https://github.com/WireGuard/wireguard-apple`) and link `WireGuardKit` to the **`IndiaVpnExtension`** target.
5. Enable **Network Extensions → Packet Tunnel** and **App Groups** (`group.com.indiavpn.mobile`) on both targets under *Signing & Capabilities* using your Apple Developer Team provisioning profiles.
6. Build & run on a physical iOS device (NetworkExtension `NEPacketTunnelProvider` tunnels do not route traffic on the iOS Simulator).
